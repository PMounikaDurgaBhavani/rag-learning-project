# Password Reset

## Overview

CloudDesk users can reset their password if they forget it or if they want to change it for security reasons.

A password reset can be performed from the CloudDesk login page without contacting support.

## How to Reset Your Password

Follow these steps to reset your CloudDesk password:

1. Open the CloudDesk login page.
2. Click the "Forgot Password" link.
3. Enter the email address associated with your CloudDesk account.
4. Click "Send Reset Link".
5. Open your email inbox.
6. Find the password reset email from CloudDesk.
7. Click the password reset link.
8. Enter a new password.
9. Confirm the new password.
10. Click "Reset Password".
11. Return to the login page and sign in using the new password.

The password reset link is valid for 30 minutes.

## Password Requirements

A new CloudDesk password must:

- Contain at least 8 characters.
- Contain at least one uppercase letter.
- Contain at least one lowercase letter.
- Contain at least one number.
- Not be the same as the previous password.

## Reset Email Not Received

If you requested a password reset but did not receive the email, wait a few minutes before requesting another link.

You should also check:

- Spam or junk folders.
- Email filtering rules.
- Whether the email address entered during the reset process is correct.
- Whether your organization's email server is blocking CloudDesk emails.

Requesting multiple reset links may invalidate previously generated links.

## Troubleshooting

| Problem | Possible Cause | Solution |
|---|---|---|
| Reset email not received | Email delivery delay | Wait a few minutes and check the spam folder |
| Reset email is in spam | Email filtering | Mark the email as safe and move it to the inbox |
| Reset link has expired | Link is older than 30 minutes | Request a new password reset link |
| Reset link is invalid | A newer reset link was generated | Use the latest reset email |
| New password rejected | Password does not meet requirements | Use a password that satisfies all password requirements |
| Password changed but login fails | Old credentials are being used | Use the newly created password |

## Security Information

CloudDesk support representatives cannot provide or reveal a user's existing password.

If you believe someone else has access to your account, reset your password immediately and contact your organization's CloudDesk administrator.

## Frequently Asked Questions

### How long is a password reset link valid?

A password reset link is valid for 30 minutes.

### Can I reuse my previous password?

No. CloudDesk does not allow the previous password to be reused.

### Can support reset my password?

Support representatives cannot directly provide or reveal your password. Use the password reset process from the login page.

### What should I do if my reset link expired?

Request a new password reset link from the login page.
