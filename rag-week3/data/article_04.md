# Ticket Search and Filtering

## Overview

CloudDesk provides search and filtering features that help users find tickets quickly.

Users can search for tickets using keywords and can narrow the results using filters such as ticket status, priority, assignee, and creation date.

## Searching for Tickets

To search for a ticket:

1. Sign in to CloudDesk.
2. Open the Tickets section.
3. Click the search field.
4. Enter a keyword, ticket number, or relevant text.
5. Press Enter or select Search.
6. Review the matching tickets.

Search results may include tickets where the search term appears in the ticket title, description, or other searchable fields.

## Filtering Tickets

Filters can be used to narrow the list of tickets.

Common filters include:

- Status
- Priority
- Assignee
- Ticket type
- Creation date
- Updated date

For example, you can filter tickets to show only open tickets assigned to a specific user.

## Filtering by Status

CloudDesk tickets can have different statuses depending on the organization's configuration.

Common statuses include:

- Open
- In Progress
- Resolved
- Closed

To filter by status:

1. Open the Tickets section.
2. Select the Status filter.
3. Select the required status.
4. Apply the filter.
5. Review the filtered results.

## Filtering by Priority

Priority filters can help users find urgent tickets.

Common priority levels include:

- Low
- Medium
- High
- Critical

To filter by priority:

1. Open the Tickets section.
2. Select the Priority filter.
3. Choose the required priority.
4. Apply the filter.
