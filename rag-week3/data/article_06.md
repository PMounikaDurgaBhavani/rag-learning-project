# File Uploads and Storage

## Overview

CloudDesk allows users to upload files to tickets and other supported areas of the application.

Uploaded files may be subject to file type, file size, and organization-level restrictions.

## Supported File Types

CloudDesk supports commonly used document and image formats.

The exact supported formats may depend on the organization's configuration.

Before uploading a file, verify that the file type is supported by the upload interface.

## File Size Limit

Individual files must not exceed the maximum file size configured for the CloudDesk organization.

If a file exceeds the configured limit, the upload will fail.

Users should reduce the file size or divide large content into multiple supported files when appropriate.

## How to Upload a File

To upload a file to a supported CloudDesk area:

1. Open the relevant ticket or record.
2. Locate the file attachment section.
3. Select "Upload File".
4. Choose the file from your device.
5. Wait for the upload to complete.
6. Confirm that the file appears in the attachment list.

Do not close the browser while an upload is still in progress.

## Upload Progress

Large files may take longer to upload depending on:

- File size.
- Internet connection speed.
- Network stability.
- Current CloudDesk service availability.

Wait until the upload completes before navigating away from the page.

## File Upload Troubleshooting

| Problem | Possible Cause | Solution |
|---|---|---|
| File upload rejected | File type is not supported | Convert the file to a supported format |
| File too large | File exceeds the organization size limit | Reduce the file size or split the content |
| Upload stops midway | Unstable network connection | Check the network and retry |
| Upload button unavailable | User lacks required permission | Contact the CloudDesk administrator |
| Upload repeatedly fails | Temporary service or network issue | Retry later and verify network connectivity |
| Uploaded file cannot be opened | File may be corrupted | Verify the original file and upload it again |

## Troubleshooting Large Files

If an upload fails because the file is too large:

1. Check the file size.
2. Compare it with the organization's configured upload limit.
3. Compress the file if appropriate.
4. Remove unnecessary content.
5. Split the content into multiple files if necessary.
6. Try uploading the smaller file again.

## Troubleshooting Upload Failures

If the file is within the allowed size and format but the upload still fails:

1. Verify your internet connection.
2. Refresh the CloudDesk page.
3. Try uploading the file again.
4. Try a different supported file.
5. Check whether other CloudDesk features are working.
6. Contact the CloudDesk administrator if the problem continues.

## File Permissions

Some CloudDesk areas may restrict who can upload or access files.

If the Upload File option is unavailable, the user's role may not have the required permission.

Contact the organization administrator to verify the required permissions.

## File Security

Do not upload confidential information unless your organization's CloudDesk policies allow it.

Users should verify the destination before uploading sensitive files.

CloudDesk administrators may apply organization-level restrictions to uploaded files.

## Frequently Asked Questions

### Why was my file rejected?

The file may use an unsupported format or exceed the configured file size limit.

### What should I do if the file is too large?

Reduce the file size, compress the file when appropriate, or split the content into smaller files.

### Why did my upload stop?

An unstable network connection or temporary service issue can interrupt an upload.

### Why can't I see the Upload File button?

Your user role may not have the required upload permission.

### Can I upload any file type?

No. CloudDesk only supports file types allowed by the upload configuration.

## Storage and Organization Limits

Storage limits may be configured at the organization level.

If the organization reaches its available storage capacity, administrators may need to review existing files or increase available storage according to the organization's CloudDesk configuration.
