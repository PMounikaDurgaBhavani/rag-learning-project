# CloudDesk User Directory

## Overview

This directory lists the CloudDesk users registered under the Northwind Support organization.

Each user has a profile ID, a name, an age, a department and a support role.

Profile records are maintained by the organization administrator and are updated at the start of every quarter.

## Access Levels

Tier 1 Agents can view and reply to tickets assigned to them.

Tier 2 Agents can view and reply to any ticket in the organization.

Team Leads and Managers can reassign tickets and view reporting dashboards.

Billing Analysts can view invoices but cannot issue refunds.

## Profile Troubleshooting

| Problem | Possible Cause | Solution |
|---|---|---|
| Profile not visible in the directory | User has not completed onboarding | Ask the administrator to activate the profile |
| Age field is blank | Date of birth was never supplied | Update the profile in Settings and re-save |
| Duplicate profile ID | Record was imported twice | Contact the administrator to merge the records |
| Role cannot be changed | Current user is not an administrator | Ask an administrator to update the role |
| Department shows as Unassigned | Import file was missing the department column | Re-import the record with the department populated |

## Related Information

Profile changes take effect at the next login. Directory records do not include contact details or salary information.
